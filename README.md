# Калькулятор MultiFRAME v2

Расчёт материалов для **потолка** и **стен** с мастером из 5 шагов.

## Запуск

```bash
npm install
npm run dev
```

Сборка для GitHub Pages:

```bash
npm run build
```

Альтернативная сборка (esbuild):

```bash
npm install
npm run build:esbuild
```

## Возможности MVP

- План помещения: прямоугольник / Г-образная форма
- Высота стен, двери и окна на стенах
- Монтаж: бескаркасный / каркасный потолок, бескаркасные / каркасные стены
- Вкладки результатов: Потолок | Стены | Итого
- Схемы укладки с подрезанными панелями (пунктир)
- PDF и share-ссылка
- Быстрый расчёт по площади (шаг 5)

## Размеры панели

| | Размер | Назначение |
|---|---|---|
| Габарит с шип-пазом | 0,75 × 0,55 м | Отображение на схеме |
| Эффективное прилегание | 0,735 × 0,535 м | Расчёт укладки (~0,39 м²) |
