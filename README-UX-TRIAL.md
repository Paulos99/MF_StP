# UX-эксперимент MultiFRAME

Это **локальная копия** калькулятора для новой модели взаимодействия.

- Оригинал: `Desktop/calc mf` — не трогаем.
- Эта папка: `Desktop/calc mf-ux-trial`
- Git только локальный, **без remote** — в репозиторий ничего не уходит.

## Запуск локально

Если установлен Node:

```bash
npm install
npm run dev
```

Без Node (достаточно Python):

```bash
py -m http.server 5173
```

Откройте: http://localhost:5173/

## Что меняется в UX

1. Старт: три выбора — размеры / нарисовать схему / по площади  
2. Режимы взаимоисключающие (нет двух источников правды L×W ↔ канвас)  
3. Баннер «Расчёт готов» + CTA проёмы / стены / share  
4. Каркас, тема, результаты — заметнее
