# Чек-лист безопасности перед открытием для пользователей

Калькулятор — статический сайт без входа, базы данных и ввода персональных данных, поэтому риск ниже, чем у кабинета.
Отметьте пункты. Результат проверки репозитория владельцем — в разделе «Что проверено» ниже.

## Сервер и сеть
- [ ] Сайт открывается только по **HTTPS** (сертификат действителен, HTTP перенаправляет на HTTPS).
- [ ] Включён `Strict-Transport-Security: max-age=31536000` (после проверки, что HTTPS работает на всём сайте).
- [ ] Каталог выпусков `.releases/` не отдаётся наружу (проверьте `https://stp-multiframe.ru/.releases/` → 404).
- [ ] Листинг каталогов выключен (`autoindex off`, по умолчанию).
- [ ] Права на файлы выпуска — только чтение для пользователя nginx; запись только у того, кто ставит выпуски.
- [ ] Сервер обновляется (ОС, nginx); доступ по SSH — по ключам, вход под root запрещён.
- [ ] Доступ к серверу и ссылке `calc` есть только у людей, ставящих выпуски.

## Заголовки
- [ ] `curl -I https://stp-multiframe.ru/calc/` показывает `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Content-Security-Policy-Report-Only`
      (файл `deploy/nginx/security-headers.conf`).
- [ ] `index.html`, `assets/*`, `version.txt` отдаются с `Cache-Control: no-cache` (скрипты и стили без хеша в имени).
- [ ] Политика CSP сейчас в режиме наблюдения; на выпуске проверена: нарушений нет. Перевод в рабочий режим — по решению владельца
      после недели наблюдения в консоли браузера.

## Данные и секреты
- [ ] В репозитории и в архиве выпуска нет паролей и ключей (проверено владельцем, см. ниже). У калькулятора нет секретов и переменных окружения.
- [ ] Калькулятор не собирает персональные данные и ничего не отправляет на сервер (проверьте во вкладке «Сеть» браузера при расчёте: запросов на ваш и чужие серверы, кроме загрузки файлов выпуска, нет).
- [ ] Метрика в калькуляторе включается только номером счётчика при сборке (`docs/handover/ENV.md`); без номера её нет. Если на сайте уже есть общий счётчик Метрики, не включайте второй для тех же страниц без согласования.

## Проверки руками после установки
- [ ] Расчёт, схема, PDF и «Поделиться» работают (см. [DEPLOY.md](DEPLOY.md)).
- [ ] Откат проверен хотя бы раз на тестовом пути до открытия сайта.
