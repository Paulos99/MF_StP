# Калькулятор MultiFRAME: документация для передачи

Адрес боевого сервиса: **https://stp-multiframe.ru/calc/**
Проверочный стенд владельца: https://paulos99.github.io/MF_StP/

Этот набор документов нужен команде интернет-маркетинга, которая размещает калькулятор на сайте `stp-multiframe.ru`.
Код вы **не правите**: изменения вносит владелец через репозиторий `Paulos99/MF_StP`.
Вы получаете проверенный выпуск (метку `vX.Y.Z` на ветке `main`) вместе с готовым архивом и устанавливаете его одной командой.

## Что это

Калькулятор MultiFRAME рассчитывает материалы для **потолка и стен**: размеры помещения, проёмы, способ монтажа, схема укладки панелей
с подрезкой, итоговая ведомость, PDF и ссылка на расчёт. Это набор **статических файлов** (HTML, JS, CSS, картинки):
серверной части, базы данных, входа и личных данных **нет**. Расчёт целиком выполняется в браузере пользователя.
Ссылка «Поделиться» хранит данные расчёта в части адреса после `#`, которая на сервер не отправляется.

```
Браузер ──HTTPS──▶ nginx stp-multiframe.ru ── /calc/ ──▶ папка выпуска (index.html, assets/, logo.png …)
Браузер ──▶ fonts.googleapis.com / fonts.gstatic.com   (только шрифт Manrope; без него — системный шрифт)
```

Сборка использует **относительные пути** (`./assets/...`), поэтому один и тот же архив работает по любому адресу
(`/calc/` на боевом сайте, `/MF_StP/` на стенде) — отдельной сборки под боевой путь не нужно.

На калькулятор ведёт Проблемомер (кнопка и QR-код в его PDF): `https://stp-multiframe.ru/calc/`. Адрес менять нельзя без согласования с владельцем.

## Два окружения

| | Стенд владельца (Павла) | Боевой: https://stp-multiframe.ru/calc/ |
|---|---|---|
| Где | GitHub Pages, подпапка `/MF_StP/` | сервер команды интернет-маркетинга |
| Кто видит | владелец (адрес открытый, но не публикуется) | пользователи |
| Как обновляется | автоматически при каждом изменении `main` | вы ставите выпуск по метке (см. [DEPLOY.md](DEPLOY.md)) |
| Сборка | та же: `npm run build:esbuild` | та же |

## Владелец и контакты

- Код, метки выпусков и репозиторий находятся у владельца: https://github.com/Paulos99/MF_StP. У команды нет доступа на запись и он не нужен.
  Репозиторий могут дорабатывать и другие участники по решению владельца; на боевой сервер попадают только выпуски с метками.
- Вопрос по сайту или новая версия — [Issues](https://github.com/Paulos99/MF_StP/issues) репозитория или сообщение владельцу напрямую.
  Контакт владельца: **[заполнит владелец перед передачей: имя, почта, мессенджер]**.
- Расчёт (размеры панели, правила укладки, количество материалов) команда не меняет и не «исправляет» на сервере.
- Доступа к вашему серверу у владельца нет; всё, что требуется от вас, описано в [DEPLOY.md](DEPLOY.md).
