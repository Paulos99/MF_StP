# Настройки и внешние адреса

## Переменные окружения

У калькулятора **нет** серверных настроек и секретов: это статический сайт с расчётом в браузере.
Файла `.env` нет и заводить его не нужно. Единственная необязательная настройка сборки — номер счётчика Яндекс.Метрики (см. ниже). Все параметры расчёта (размеры панели, правила монтажа, количество материалов)
находятся в коде (`src/core/constants.js`, `src/calculators/`) и меняются только выпуском владельца.

## Адреса, к которым обращается страница

| Адрес | Зачем | Что будет, если недоступен |
|---|---|---|
| `https://stp.store/...` (ссылка, не загрузка) | кнопка «Купить MultiFRAME»: открывается по клику в новой вкладке | кнопка ведёт на недоступную страницу |

Скриптов, стилей, шрифтов и данных с чужих серверов страница не загружает (шрифт Manrope лежит в сборке, `assets/fonts/`). Единственное исключение — Яндекс.Метрика, если включён её счётчик (см. ниже): тогда после согласия посетителя загружается `https://mc.yandex.ru/metrika/tag.js`.

## Яндекс.Метрика (по желанию)

По умолчанию счётчика нет: ни скрипта, ни баннера, страница не меняется. Номер счётчика (только цифры) задаётся при сборке одним из способов:

| Способ | Где |
|---|---|
| переменная окружения при сборке `VITE_YM_ID` | `VITE_YM_ID=12345678 npm run build:esbuild` |
| файл `metrika.config.json` в корне репозитория | `{ "counterId": 12345678 }` (номер счётчика не секрет: он виден в коде любой страницы) |

Рабочий процесс выпуска по метке ничего не передаёт в `VITE_YM_ID`, поэтому для выпуска номер вносят в `metrika.config.json` обычным запросом на слияние и выпускают новую метку (это делает владелец).

Как работает: при заданном номере в `index.html` добавляется `window.MF_YM_ID`, а `src/ui/metrika.js` показывает баннер «Принять / Отказаться»; скрипт Метрики грузится только после согласия (выбор хранится в `localStorage`, ключ `mf_calc_ym_consent`). Запись экранов (Вебвизор) выключена. На стенде (`*.github.io`) и на `localhost` Метрика не включается никогда.

## Хранилище в браузере

- `localStorage`: ключ `mf_theme` (светлая/тёмная тема) и, если включена Метрика, `mf_calc_ym_consent` (выбор посетителя). Персональных данных нет.
- Данные расчёта в ссылке «Поделиться» лежат в части адреса после `#` (размеры комнаты и параметры монтажа), на сервер не уходят.
